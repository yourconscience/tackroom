Each file below is the vendor's own mark as published, retrieved on 2026-11-13 unless its row gives another date. Nothing is redrawn, recoloured or optimised. A file that came from a zip was extracted as a single entry. Tern and Rex are PNG app icons converted from the installed app's `.icns` to 128x128 with `sips`. Two rows (Codex, Grok) are not vendor files: the official source could not be fetched, so they are the marks the tackroom site sprite already carried, extracted unchanged into standalone SVGs. One row (Antigravity CLI) comes from the pinned `@lobehub/icons-static-svg` package because Google publishes no downloadable file; its MIT licence covers the drawing, not the mark. One row (Kiro) has no file yet: its mark is still to be retrieved.
